## Projects

| Project | Topic | What it does |
| --- | --- | --- |
| [Titanic Survival Exploration](titanic_survival_exploration) | Intro / decision rules | Predicts passenger survival with hand-built decision rules |
| [Boston Housing](boston_housing) | Regression | Predicts house prices with a tuned decision-tree regressor (grid search, cross-validation) |
| [Finding Donors](finding_donors) | Supervised learning | Finds likely donors (income > $50K) by comparing several classifiers on census data |
| [Student Intervention](student_intervention) | Supervised learning | Identifies students who may need early intervention |
| [Creating Customer Segments](creating_customer_segments) | Unsupervised learning | Segments wholesale customers with PCA and clustering |
| [Smartcab](smartcab) | Reinforcement learning | Trains a self-driving cab agent with Q-learning |
| [Dog Breed Predictor](Dog%20Breed%20Predictor) | Deep learning | Classifies dog breeds from images with a CNN and transfer learning |
| [Technical Interview](technical_interview) | Algorithms | Solutions to interview-style algorithm questions with complexity analysis |
| [Capstone: Urban Sound](Udacity-ML-Capstone-master(UrbanSound)) | Audio classification | Classifies urban sounds (UrbanSound8K) from audio features |

## Run a project
